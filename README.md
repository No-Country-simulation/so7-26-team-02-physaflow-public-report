# PhysaFlow Public Report

Public website for the PhysaFlow report about **Stranded Capacity** in AI data centers.

## Tech Stack

- Next.js
- React
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

## Branches

- `main` → Production
- `develop` → Development
- `feature/*` → New features
